# AI 채팅과 대화 기록

[전체 기능](../README.md) · [상담사 연결](../COUNSEL_WORK_SUMMARY.md) · [API 연동](../CHAT_API_WORK_SUMMARY.md)

첫 화면 `/#/`와 `/#/ai`에서 질문합니다. 화면은 답변을 생성하지 않고, 서버에 접수한 작업을 조회해 답변과 자료를 표시합니다.

## 질문에서 답변까지

| 단계 | 화면의 동작 | 서버와의 연결 |
|---|---|---|
| 입력 | 한글 조합 중 Enter 전송 방지, 빈 입력 검사, 중복 전송 잠금 | 질문과 현재 대화 ID 전송 |
| 접수 | 접수한 작업 ID와 대화 ID 보관 | `POST /api/chat/questions` |
| 대기 | 대기·검색·자료 조회·모델 대기·생성 단계를 표시 | `GET /api/chat/jobs/{jobId}` |
| 완료 | 문장과 상품·본인 정보·매장 카드를 표시 | 서버의 성공·실패·재시도 가능 여부 사용 |
| 실패 | 오류 안내, 재시도 가능한 최종 실패는 같은 질문의 멱등키로 재시도 | `POST /api/chat/questions/retries` |
| 중단 | 사용자 요청으로 작업 취소를 보내고 늦게 도착한 응답 무시 | `POST /api/chat/jobs/{jobId}/cancel` |

평상시 조회 간격은 1.5초입니다. 429·5xx·네트워크 오류에는 백오프를 적용합니다. 재시도 가능한 실패에 한해 자동 재시도하며, 서버 시도 횟수와 FE의 최대 3회 제한을 함께 확인합니다. 새 대화·로그아웃 때 조회를 멈추는 것과 사용자가 작업 중단을 요청하는 것은 별도 동작입니다.

## 답변을 다른 방식으로 확인하기

로그인한 회원은 성공한 답변 아래에서 **일반 문의·매장 찾기·내 정보 확인·상품 정보**로 다시 검색할 수 있습니다. 원래 답변을 바꾸지 않고 의도별 결과를 덧붙입니다. 서버가 이미 처리한 의도는 잠그고, 서버 처리 여부를 알 수 없는 네트워크 실패만 다시 요청할 수 있습니다.

일반 질문은 서버가 위치를 요구했을 때만 위치 권한을 요청합니다. 매장 의도 재검색은 버튼을 누를 때 위치를 받으며, 실패하면 지역명을 넣어 다시 질문하도록 안내하고 재검색 요청을 보내지 않습니다.

매장 답변은 지도·길찾기로, 상품 답변은 상세·가입 화면으로 연결합니다. 본인 정보 카드는 서버가 반환한 회선·사용량·청구 자료를 표시합니다. 답변의 좋아요·아쉬워요는 사유와 의견을 기존 고객 문의 API에 남깁니다. 의견을 제출했다고 즉시 모델을 학습시키는 기능은 아닙니다.

## 회원과 대화 기록

비회원 질문에는 게스트 세션 쿠키를 함께 보냅니다. 로그인 후 대화 승계는 서버의 인증·게스트 세션 처리와 연결됩니다. 토큰은 공용 인증 상태가 관리하며, 만료된 토큰의 동시 재발급 요청은 하나로 합칩니다. 일시적인 네트워크 오류만으로 로그아웃시키지 않습니다.

회원은 최근 대화 목록에서 기존 문답을 열거나 삭제하고 이전 목록 페이지를 불러옵니다. 대화에 상담 기록이 있으면 서버의 통합 타임라인을 표시합니다. 일반 AI 대화를 다시 열 때는 저장된 질문·답변을 복원하며, 실시간 답변의 모든 카드·의도별 재검색 상태까지 복원하는 것은 아닙니다.

인기·급상승·지역별 FAQ를 선택하면 회원은 선택 당시 문답을 서버에 저장합니다. 비회원은 화면에서만 확인합니다. 상담 호출은 현재 대화 ID를 보내므로 저장한 FAQ도 자동으로 인계됩니다. [상담 종료 후 이어가기](../COUNSEL_WORK_SUMMARY.md)를 참고하세요.
