# 상품과 내 이용 정보

[전체 기능](../README.md) · [AI 응답 카드](chat-and-history.md) · [고객 지원](customer-support.md)

고객은 `/#/store`에서 상품을 비교하고 `/#/my`에서 본인 회선과 가입 내역을 확인합니다. 상품 목록·상세는 공개 API이며, 가입·변경·본인 정보 조회는 로그인이 필요합니다.

## 탐색에서 가입까지

요금제·결합상품·부가서비스·로밍·인터넷·IPTV를 조회합니다. 검색·조건 필터·상세 설명을 확인한 뒤 가입 화면으로 이동합니다. 가입할 회선, 희망 번호, 이용 기간 등 업무에 필요한 값을 입력하고 서버 결과를 받습니다.

| 업무 | 제공하는 화면 동작 |
|---|---|
| 회선 | 신규 가입과 희망 번호 중복 확인, 본인 회선 선택·해지 |
| 요금제 | 현재 요금제 조회와 변경 |
| 부가서비스 | 가입·해지, 요금제 포함 서비스의 해지 제한 안내 |
| 로밍 | 기간 지정 예약, 시작 전 취소 |
| 결합 | 결합 생성, 대표·구성 회선 확인, 본인 회선 추가·탈퇴 |
| 인터넷·IPTV | 홈서비스 가입·조회·해지 |

서버가 회선 소유권·상태와 변경 조건을 검사합니다. 화면은 실패 이유를 표시하고 성공한 영역을 다시 조회합니다. 회선 해지나 대표 회선 탈퇴처럼 관련 가입 상태에 영향을 주는 동작은 확인 화면을 거칩니다.

## MY에서 확인하는 정보

회원 정보 조회·수정, 다회선 정보, 현재 요금제, 약정, 결합, 부가서비스, 로밍, 사용량과 청구 내역을 조회합니다. 항목별로 요청하므로 한 항목이 실패해도 다른 조회 결과를 유지합니다. 예약·문의·알림도 MY와 고객센터에서 다시 확인할 수 있습니다.

### 금액과 사용량을 읽는 기준

- **저장 청구 내역**은 서버의 청구 기록을 조회합니다. **예정 청구액**은 화면에서 월정액·가입 상품·할인·할부 등을 조합한 추정치입니다.
- MY의 데이터 잔량 영역은 현재 요금제의 제공량 전체를 잔량으로 표시하는 부분이 있습니다. 실시간 망 사용량을 측정한 값이 아닙니다.
- AI 답변의 사용량 카드는 서버가 준 사용량·제공량·남은 양을 표시합니다. MY의 제공량 기준 표시와는 다릅니다.
- 가입·변경은 서비스 내부의 가입 기록 API와 연결합니다. 실제 통신사 개통·결제나 변경 시점의 일할 청구 정산을 수행한다는 뜻은 아닙니다.

## 관리자 관리

`/#/admin/products`에서 상품 종류별 목록·검색·상세·등록·수정·활성 상태·삭제 목록을 관리합니다. 요금제에 포함할 부가서비스도 설정합니다. 삭제된 상품의 복구 화면은 제공하지 않습니다.
